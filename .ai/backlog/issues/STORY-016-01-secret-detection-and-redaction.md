# STORY-016-01: Secret detection and redaction

**Epic:** EPIC-016 — Security & Threat Protection

## Description

As a security engineer, I want prompt and payload secret detection so that sensitive data is not sent to providers unintentionally.

## Acceptance Criteria

- Secret scanners identify sensitive content.
- Redaction can be applied according to policy.
- Findings are logged securely.

# STORY-012-04: Credential rotation support

**Epic:** EPIC-012 — Secrets & Credential Management Integration

## Description

As a security team, I want credential rotation processes so that provider secrets can be rotated safely.

## Acceptance Criteria

- Credentials can be rotated without service outage.
- Rotation events are auditable.
- Old credentials are invalidated.

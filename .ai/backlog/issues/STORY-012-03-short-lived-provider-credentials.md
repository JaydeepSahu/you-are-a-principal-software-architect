# STORY-012-03: Short-lived provider credentials

**Epic:** EPIC-012 — Secrets & Credential Management Integration

## Description

As an operator, I want short-lived credentials where supported so that provider access keys rotate frequently.

## Acceptance Criteria

- Short-lived credential issuance is supported.
- Credentials expire automatically.
- Rotation workflows are documented.

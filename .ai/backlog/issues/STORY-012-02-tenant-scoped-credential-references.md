# STORY-012-02: Tenant-scoped credential references

**Epic:** EPIC-012 — Secrets & Credential Management Integration

## Description

As a tenant admin, I want credential references scoped to my tenant so that provider secrets are isolated.

## Acceptance Criteria

- Credentials include tenant metadata.
- Tenant isolation prevents cross-tenant access.
- Credential references are auditable.

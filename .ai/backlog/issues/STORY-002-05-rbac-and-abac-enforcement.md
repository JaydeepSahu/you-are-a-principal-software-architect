# STORY-002-05: RBAC and ABAC enforcement

**Epic:** EPIC-002 — Identity & Tenant Service

## Description

As a policy author, I want the identity service to expose RBAC and ABAC attributes so that runtime authorization decisions can use both role and attribute data.

## Acceptance Criteria

- Role assignments are stored and returned.
- Attribute-based claims are available for policy evaluation.
- Access checks can be performed using platform attributes.

# STORY-005-05: Registry search and discovery

**Epic:** EPIC-005 — Provider & Model Registry

## Description

As a portal user, I want the model registry to be searchable so that I can discover available provider/model combinations.

## Acceptance Criteria

- Search supports provider, model, capability, and region.
- Results include key metadata.
- Search performance is adequate for UI usage.

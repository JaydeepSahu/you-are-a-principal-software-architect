# STORY-010-04: Cache invalidation and expiry

**Epic:** EPIC-010 — Semantic & Exact Cache

## Description

As an operator, I want cache invalidation and expiration support so that stale responses are not reused.

## Acceptance Criteria

- Cache entries expire automatically.
- Entries can be invalidated by policy change.
- Invalidation is traceable.

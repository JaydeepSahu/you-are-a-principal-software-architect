# STORY-017-02: CI/CD pipeline automation

**Epic:** EPIC-017 — Deployment, CI/CD & Runbooks

## Description

As a release engineer, I want CI/CD pipelines for build, test, and deployment so that changes are delivered reliably.

## Acceptance Criteria

- Pipelines build and test services.
- Successful builds produce deployable artifacts.
- Deployments are automated to target environments.

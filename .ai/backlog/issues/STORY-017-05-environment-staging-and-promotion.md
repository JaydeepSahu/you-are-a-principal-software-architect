# STORY-017-05: Environment staging and promotion

**Epic:** EPIC-017 — Deployment, CI/CD & Runbooks

## Description

As a release manager, I want staged environments and promotion workflows so that deployments progress safely from dev to prod.

## Acceptance Criteria

- Staging environment deployment is supported.
- Promotions are reproducible.
- Rollback procedures exist.

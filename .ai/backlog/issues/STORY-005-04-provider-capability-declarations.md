# STORY-005-04: Provider capability declarations

**Epic:** EPIC-005 — Provider & Model Registry

## Description

As a governance author, I want providers to declare supported features so that the platform can advertise capabilities accurately.

## Acceptance Criteria

- Capabilities like streaming, embeddings, and tool support are declared.
- Unsupported features are not presented.
- Capability metadata is versioned.

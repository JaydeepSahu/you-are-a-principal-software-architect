# STORY-013-05: Portal BFF aggregation

**Epic:** EPIC-013 — Developer Portal & Portal BFF

## Description

As a portal service, I want a BFF that aggregates backend APIs so that portal pages can render quickly and securely.

## Acceptance Criteria

- BFF endpoints aggregate necessary data.
- API responses are scoped to the current tenant.
- BFF respects portal authentication.

# STORY-004-02: Cost-aware routing

**Epic:** EPIC-004 — Routing & Optimization Service

## Description

As a finance stakeholder, I want the routing service to prefer lower-cost providers/models when quality and policy allow so that spend is optimized.

## Acceptance Criteria

- Routing can rank routes by estimated cost.
- Cost thresholds are configurable by policy.
- Expensive routes are chosen only when required.

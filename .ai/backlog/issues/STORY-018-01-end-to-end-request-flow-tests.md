# STORY-018-01: End-to-end request flow tests

**Epic:** EPIC-018 — Testing, Observability & SLOs

## Description

As a QA engineer, I want end-to-end tests covering AI request flows so that the platform behavior is validated under realistic conditions.

## Acceptance Criteria

- E2E tests cover gateway, routing, adapter, and response behavior.
- Tests can run in CI.
- Failures are actionable.

# STORY-020-04: Onboarding guides for operators

**Epic:** EPIC-020 — Documentation, ADRs, and Governance

## Description

As a new operator, I want onboarding guides so that I can understand deployment, runbooks, and operational practices.

## Acceptance Criteria

- Onboarding guides cover setup and runbooks.
- Guides include key operational contacts.
- Guides are easy to navigate.

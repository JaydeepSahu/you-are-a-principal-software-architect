# STORY-018-05: Regression and integration test automation

**Epic:** EPIC-018 — Testing, Observability & SLOs

## Description

As a QA lead, I want regression and integration tests automated so that platform changes don't break core functionality.

## Acceptance Criteria

- Regression tests run in CI.
- Integration tests validate cross-service interactions.
- Test failures prevent unsafe merges.

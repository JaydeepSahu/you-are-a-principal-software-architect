# STORY-017-04: Deployment validation checks

**Epic:** EPIC-017 — Deployment, CI/CD & Runbooks

## Description

As an operator, I want deployment validation checks so that configuration and manifest issues are detected before rollout.

## Acceptance Criteria

- Validation checks run in the pipeline.
- Failed checks block deployment.
- Issues are reported clearly.

# STORY-006-02: GitHub Copilot adapter

**Epic:** EPIC-006 — Provider Adapter Host & Adapters

## Description

As a provider integration lead, I want a GitHub Copilot adapter so that the platform can route eligible requests to Copilot.

## Acceptance Criteria

- Adapter can authenticate to Copilot.
- Requests are transformed into Copilot-compatible calls.
- Responses are normalized back to the platform contract.

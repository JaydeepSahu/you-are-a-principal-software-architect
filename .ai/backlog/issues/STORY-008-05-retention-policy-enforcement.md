# STORY-008-05: Retention policy enforcement

**Epic:** EPIC-008 — Audit & Compliance Service

## Description

As a data protection officer, I want audit retention policies enforced so that records are kept only as long as required.

## Acceptance Criteria

- Retention rules can be configured by event type.
- Old audit data is archived or deleted per policy.
- Retention actions are logged.

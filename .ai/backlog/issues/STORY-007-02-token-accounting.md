# STORY-007-02: Token accounting

**Epic:** EPIC-007 — Metering & Cost Service

## Description

As a finance owner, I want token usage to be accounted by tenant, application, and user so that cost can be attributed accurately.

## Acceptance Criteria

- Input/output tokens are tracked per request.
- Aggregates can be queried by tenant/application.
- Cost estimates are calculated from pricing metadata.

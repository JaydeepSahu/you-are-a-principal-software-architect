# STORY-008-03: Administrative action auditing

**Epic:** EPIC-008 — Audit & Compliance Service

## Description

As a security lead, I want administrative changes logged so that changes to configuration and policy are traceable.

## Acceptance Criteria

- Admin actions include actor, timestamp, and change details.
- Audit records are immutable.
- Audit queries can filter by action type.

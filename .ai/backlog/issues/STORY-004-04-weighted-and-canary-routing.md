# STORY-004-04: Weighted and canary routing

**Epic:** EPIC-004 — Routing & Optimization Service

## Description

As a release manager, I want the routing service to support weighted and canary routes so that traffic can be shifted gradually.

## Acceptance Criteria

- Route weights can be specified per tenant or deployment.
- Canary routes can receive a controlled percentage of traffic.
- Traffic distribution is observable.

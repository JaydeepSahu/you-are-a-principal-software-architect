# STORY-005-01: Provider catalog API

**Epic:** EPIC-005 — Provider & Model Registry

## Description

As an operator, I want a provider catalog that lists supported AI providers so that routing and policy can reference available options.

## Acceptance Criteria

- Providers have metadata, category, and capability flags.
- Catalog entries are queryable.
- Providers can be enabled/disabled.

# STORY-002-01: Enterprise IdP federation

**Epic:** EPIC-002 — Identity & Tenant Service

## Description

As an admin, I want the platform to federate with the enterprise identity provider so that users authenticate with corporate credentials.

## Acceptance Criteria

- OIDC/SAML login works with the configured IdP.
- User claims are mapped to platform identities.
- Failed federation attempts return clear errors.

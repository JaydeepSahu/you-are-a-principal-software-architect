# STORY-019-02: Cost-aware model ranking

**Epic:** EPIC-019 — Cost Optimization & Budgets

## Description

As a cost analyst, I want model selection to factor pricing and quality so that cost/quality tradeoffs are visible.

## Acceptance Criteria

- Models are ranked by estimated cost and capability.
- Routing metadata includes cost estimates.
- Cost-based decisions can be audited.

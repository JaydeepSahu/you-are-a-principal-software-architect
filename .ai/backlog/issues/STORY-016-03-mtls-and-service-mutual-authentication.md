# STORY-016-03: mTLS and service mutual authentication

**Epic:** EPIC-016 — Security & Threat Protection

## Description

As an infrastructure engineer, I want mTLS between services so that service-to-service traffic is authenticated and encrypted.

## Acceptance Criteria

- Services authenticate via mutual TLS.
- Certificates are rotated securely.
- Unauthorized services are denied.

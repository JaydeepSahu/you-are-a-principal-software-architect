# STORY-005-03: Deployment metadata and regions

**Epic:** EPIC-005 — Provider & Model Registry

## Description

As a compliance lead, I want model deployments to include region and data residency constraints so that route selection can honor residency rules.

## Acceptance Criteria

- Deployments include region and residency metadata.
- Routing can filter deployments by region.
- Policies can reference deployment residency.

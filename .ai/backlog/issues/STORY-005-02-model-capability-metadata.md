# STORY-005-02: Model capability metadata

**Epic:** EPIC-005 — Provider & Model Registry

## Description

As a product manager, I want model entries to include capabilities, context window, pricing, and supported modalities so that selection is accurate.

## Acceptance Criteria

- Models include capability, pricing, and region metadata.
- Unsupported capabilities are excluded.
- Metadata is available to routing and policy services.

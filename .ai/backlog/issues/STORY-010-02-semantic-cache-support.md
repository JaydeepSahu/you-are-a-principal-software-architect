# STORY-010-02: Semantic cache support

**Epic:** EPIC-010 — Semantic & Exact Cache

## Description

As an efficiency lead, I want semantic cache support so that semantically similar requests can reuse earlier responses when allowed.

## Acceptance Criteria

- Semantic similarity search can be performed.
- Cache hits are returned when policy allows.
- Semantic cache metadata is tenant-scoped.

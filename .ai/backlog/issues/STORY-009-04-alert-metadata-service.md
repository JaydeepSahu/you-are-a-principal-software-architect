# STORY-009-04: Alert metadata service

**Epic:** EPIC-009 — Observability Control Service

## Description

As an on-call engineer, I want alert metadata managed centrally so that alerts are consistent and actionable.

## Acceptance Criteria

- Alert definitions include severity and runbooks.
- Alerts can be linked to SLO violations.
- Alert metadata is queryable.

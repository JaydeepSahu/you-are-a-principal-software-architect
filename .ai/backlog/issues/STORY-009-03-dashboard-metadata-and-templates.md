# STORY-009-03: Dashboard metadata and templates

**Epic:** EPIC-009 — Observability Control Service

## Description

As an operator, I want dashboard metadata and templates so that key platform health views are available quickly.

## Acceptance Criteria

- Dashboard templates are available for core services.
- Templates include request, latency, and error views.
- Templates are versioned.

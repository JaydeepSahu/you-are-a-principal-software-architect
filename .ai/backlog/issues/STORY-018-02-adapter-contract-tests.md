# STORY-018-02: Adapter contract tests

**Epic:** EPIC-018 — Testing, Observability & SLOs

## Description

As a developer, I want contract tests for provider adapters so that adapter behavior remains stable across changes.

## Acceptance Criteria

- Adapters expose contract test suites.
- Contract tests verify request/response schemas.
- Adapter changes are validated against contracts.

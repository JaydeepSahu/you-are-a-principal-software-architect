# STORY-002-03: Application and service principal management

**Epic:** EPIC-002 — Identity & Tenant Service

## Description

As a platform operator, I want to register applications and service principals so that machine clients can authenticate securely.

## Acceptance Criteria

- Applications can be registered with tenant scope.
- Service principals can be created and revoked.
- API credential metadata is stored without exposing secrets.

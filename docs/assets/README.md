# Assets

This directory contains static assets utilized by the documentation portal.

## Usage Guidelines
- **Binary Media**: Use this folder for `.png`, `.jpg`, or `.gif` files that represent UI screenshots, brand logos, or complex diagrams that cannot be expressed via Mermaid.js.
- **Referencing Assets**: When embedding an asset in a markdown file, use relative paths. 
  - Example: `![Architecture Overview](../assets/architecture-overview.png)`
- **Optimization**: Please compress all images using standard tools (like TinyPNG or squoosh) before committing them to keep the repository lightweight.

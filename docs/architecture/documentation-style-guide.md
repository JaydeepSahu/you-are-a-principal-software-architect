# Documentation Style Guide

This page defines the documentation style guide for the Enterprise AI Platform.

## Purpose

- Maintain consistent tone and presentation across the docs portal.
- Reduce friction for new contributors writing documentation.
- Ensure documentation is clear, concise, and enterprise-ready.

## Tone and Voice

- Use professional, neutral language.
- Prefer direct and active voice.
- Avoid jargon without context.
- Keep paragraphs short and scannable.

## Structure

- Use headings to outline sections clearly.
- Use paragraphs, lists, and callouts for readability.
- Keep content focused on one concept per section.

## Formatting

- Use sentence case for headings.
- Use code formatting for commands, file names, and paths.
- Keep list items short and parallel.
- Use admonitions for important notes, warnings, and tips.

## Review

- Update documentation with every significant code or design change.
- Review docs as part of pull request quality checks.

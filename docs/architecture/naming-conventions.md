# Naming Conventions

This page defines naming conventions for the Enterprise AI Platform documentation and repository.

## Purpose

- Ensure consistent naming across docs, filenames, and repository artifacts.
- Help contributors find and update related documentation.

## Documentation

- Use descriptive file names in lowercase with hyphens for docs.
- Examples: `architecture-overview.md`, `api-guidelines.md`.
- Use `index.md` for directory landing pages.

## Git and Branches

- Use meaningful branch names that describe the change.
- Example: `feature/docs-material-setup`, `fix/security-docs`

## Code and Config

- Use PascalCase for C# types and records.
- Use camelCase for JSON properties and configuration keys.
- Use kebab-case for Markdown filenames and URL paths.

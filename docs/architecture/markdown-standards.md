# Markdown Standards

This page defines Markdown standards for the Enterprise AI Platform documentation.

## General Rules

- Use UTF-8 encoding.
- Keep line lengths readable (80-120 characters where practical).
- Use headings to organize content hierarchically.
- Prefer fenced code blocks for code examples.

## Headings

- Use `#` for top-level sections.
- Use incremental heading levels without skipping levels.
- Use sentence case for heading text.

## Code Blocks

- Use triple backticks for code blocks.
- Specify the language when possible.
- Keep examples minimal and relevant.

## Lists

- Use hyphens for bullet lists.
- Keep list items concise.
- Use proper punctuation consistently.

## Links and References

- Use relative links for repository docs.
- Use absolute URLs for external references.
- Keep link text descriptive and actionable.
